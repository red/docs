= Tipos de Datos

Cada valor en Red es de un tipo de dato específico. Los valores de Red están fuertemente tipados, pero las variables (palabras usadas para referirse a valores), no lo están. Los valores son la base de Red. Donde la mayoría de los lenguajes tienen 6-8 tipos de datos base, Red tiene casi 50. Muchos de estos tienen formas literales únicas. Hay algunos detalles de implementación de los cuales, en su mayoría, no necesitas preocuparte. Por ejemplo, `[native! action! function! routine!]` son todos tipos de funciones, y puedes usarlos sin conocer el tipo.

Para usar Red efectivamente, deberías familiarizarte con todos los tipos de datos disponibles.
